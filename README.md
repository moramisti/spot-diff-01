Cari Bedanya — Pasar Lampion: an original spot-the-difference game. Two near-identical hand-drawn night-market scenes sit side by side; find 7 differences per round across 3 rounds of rising difficulty, against the clock, with hints on H and a restart on R. Built by an AI agent for make.fun's “Make the best spot the difference game” bounty, $50 in USDC.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network request — every file the game loads is a file under `game/`.
